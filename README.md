# نظام الامتحانات الإلكترونية — نسخة محلية بالكامل

هذه النسخة لا تستخدم Firebase أو أي خدمة Backend أو API خارجي.

## التخزين
- بيانات الأستاذ والامتحانات والأسئلة وإجابات الطلاب والنتائج والمخالفات تُحفظ في `localStorage` داخل المتصفح.
- تسجيل دخول الأستاذ محلي باستخدام:
  - Username: `Masterpiecemwe@gmail.com`
  - Password: `13579Mwe2468`
- الطلاب يدخلون بالاسم ورمز الامتحان، وتُحفظ بياناتهم محليًا في نفس المتصفح.

## تشغيل الموقع
يمكن فتح `index.html` مباشرة، أو نشر الملفات كما هي على GitHub Pages.

## تنبيه مهم
لأن النظام محلي بالكامل ولا يوجد خادم، فإن البيانات ليست مشتركة بين أجهزة مختلفة. إذا دخل الأستاذ من جهاز والطالب من جهاز آخر، فلن يرى كل منهما بيانات الآخر. هذه النسخة مناسبة للاستخدام المحلي/التجريبي، وليست قاعدة بيانات سحابية متعددة الأجهزة.

## كتابة الأسئلة دفعة واحدة
من صفحة تعديل الامتحان اضغط «كتابة عدة أسئلة دفعة واحدة». افصل بين الأسئلة بسطر فارغ:

```
What is the capital of France?
A) Berlin
B) Paris *
C) Madrid
D) Rome
Points: 2

The sun rises in the west.
TF: false

Write the past tense of "go".
Answer: went, Went

Write a short paragraph about your daily routine.
Essay
Points: 5
```
- اختيار من متعدد: أربعة اختيارات A–D، والصحيح بعلامة `*` أو سطر `Answer: B`.
- صح/خطأ: `TF: true` أو `TF: false`.
- إجابة قصيرة: `Answer:` والإجابات المقبولة مفصولة بفاصلة.
- مقالي: سطر `Essay`.
- الدرجة اختيارية `Points: 2` (الافتراضي 1).
